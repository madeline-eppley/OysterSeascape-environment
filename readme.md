# environmental data
##### last updated by MGE on 8/5/2025

### final data location
`seascape_allfinal_envr_20250704.csv` contains the final environmental data for 33 sites in the seascape analysis that contain high-quality, representative salinity and temperature data. Sites that are included in this file met the baseline requirements of at least 1 year of measurements, minimum 6 months of data (to capture seasonality), at least 1 measurement per day, and recent data within the past 5 years. 

### Non-correlated environmental variables include
- temperature and salinity quantiles (.1 and .9 for both)
- standard deviation

### large files
