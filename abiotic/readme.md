### large files

- SC1_raw_temp.csv
- RI2_raw.csv
- NH1_raw.csv
- NC1_raw.csv
- LA3_raw.csv
- GA3_raw.csv
- FL2_raw.csv
- FL1_raw.csv
- AL1_raw.csv
