## qPCR data

### File structure
Full lab protocols are available in the Lotterhos Lab qPCR protocol PDF. Raw outputs of the Bio-Rad CFX96 Real-Time System with Bio-Rad CFX Maestro software are available in the raw qPCR folder. Proccessed population-level and individual-level data with varying Cq cutoffs are in the main branch of the biotic subfolder.

Other qpcr information, including additional raw run files and lab protocols can be found here, with viewer access granted upon request to (eppley.madeline@gmail.com): [qPCR google drive](https://drive.google.com/drive/u/0/folders/1cE7RjwwL4LNCk9fhJ-Di_gMGhmh1MR28)
